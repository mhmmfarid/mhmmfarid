# 🚀 Proyek Unggulan

## 🏥 Sistem Informasi Rumah Sakit (SIMRS)

Sistem Informasi Rumah Sakit berbasis web yang dikembangkan untuk membantu digitalisasi proses pelayanan dan administrasi rumah sakit. Sistem ini mengintegrasikan pengelolaan data pasien, dokter, rekam medis, jadwal praktik, farmasi, hingga laporan operasional sehingga seluruh proses menjadi lebih efektif, terstruktur, dan efisien.

**Teknologi**

- Laravel
- Filament
- MySQL
- Tailwind CSS

🔗 Repository  
https://github.com/mhmmfarid/rumahsakit

**Teknologi**

- MySQL
