# 🚀 Proyek Unggulan

## 🏥 Sistem Informasi Rumah Sakit (SIMRS)

Sistem Informasi Rumah Sakit berbasis web untuk membantu digitalisasi pelayanan dan administrasi rumah sakit. Sistem mencakup pengelolaan pasien, dokter, rekam medis, farmasi, jadwal praktik, serta laporan operasional.

**Teknologi:** Laravel • Filament • MySQL • Tailwind CSS

🔗 https://github.com/mhmmfarid/rumahsakit

---

## 🏢 Sistem Manajemen Data PT Telkom

Aplikasi berbasis web yang mendukung proses administrasi dan pengelolaan data operasional di lingkungan PT Telkom sehingga proses pencatatan, pencarian, serta monitoring data menjadi lebih efisien.

**Teknologi:** Php Native • MySQL

🔗 https://github.com/mhmmfarid/ptelkm

---

## 📂 Sistem Arsip Digital BRI

**Teknologi:** Php • MySQL

🔗 https://github.com/mhmmfarid/bri_arsip

## 🚗 Sistem Informasi Car Wash
